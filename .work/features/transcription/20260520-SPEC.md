# tools-transcript - Transcription

**Version:** 20260520 · **Status:** Draft (foundation)  
**Bounded context:** `transcription`  
**ADRs:** 001, 002, 004

---

## 1. Purpose

Transcribe audio/video files from `./sources` to `.txt` and `.srt` in `./outputs` using whisper.cpp inside an isolated Docker stack.

---

## 2. In scope

- Accept media path relative to `/sources` inside container.
- Auto-extract audio from video (ffmpeg) when input is video.
- Run `whisper-cli` with configured ggml model.
- Write `<basename>.txt` and `<basename>.srt` to `/outputs`.
- Exit codes: `0` success, `1` usage, `2` runtime failure.

## 3. Out of scope

- Cloud upload or streaming.
- Speaker diarization.
- Real-time microphone capture.
- Committing user media to git.

---

## 4. Domain language

| Term | Meaning |
|------|---------|
| Source file | User media under `./sources` |
| Artifact | `.txt` or `.srt` under `./outputs` |
| Model | ggml weights (e.g. `ggml-medium.bin`) |

---

## 5. Rules

| ID | Rule |
|----|------|
| R1 | Input path must resolve under `/sources`; reject `..` and absolute paths outside mount |
| R2 | If input is video (mp4, mkv, webm, …), extract mono 16kHz WAV to `/outputs/.tmp/` before whisper |
| R3 | Default model from `WHISPER_MODEL` env; fail fast if model file missing after download attempt |
| R4 | Always emit both `-otxt` and `-osrt` unless `--format` override added in future amendment |
| R5 | Do not log raw transcript text at INFO level (privacy) |
| R6 | `./sources` and `./outputs` remain gitignored |

---

## 6. Data model

Ephemeral filesystem only — no database.

---

## 7. APIs

CLI only:

```bash
./bin/start.sh transcribe myvideo.mp4
# equivalent: docker compose run --rm transcript transcribe myvideo.mp4
```

---

## 8. Invariants

- Container has read access to `/sources`, write to `/outputs` and model volume.
- No published host ports required for R1–R4.

---

## 9. Errors

| Condition | Exit | Message (stderr) |
|-----------|------|------------------|
| Missing file | 1 | `source not found: …` |
| ffmpeg failure | 2 | `audio extraction failed` |
| whisper failure | 2 | `transcription failed` |

---

## 10. Observability

- Log: file name (not content), model, duration seconds, exit status.
- See `.ai/standards/20260520-observability-spec.md`.

---

## 11. Security

- Treat all source media as confidential user data.
- No network egress required for core path.
